Put it together and the opening line makes sense: SQLite competes with fopen, not with Oracle. It is in-process, one ordinary file, with zero configuration. Its test code is 590 times the size of the library, with 100 percent branch and MC/DC coverage. And it is in the public domain, free for any purpose with no license. So the takeaway for us is practical: wherever you would have reached for fopen and a home-grown file format, reach for SQLite instead.
