Why trust a library that sits in a trillion places? Look at the testing. As of version 3.42.0, the library is about 155.8 thousand lines of C, and the project carries about 92 million lines of test code and test scripts, roughly 590 times as much. The two squares are drawn to scale. That test effort is split across four independent harnesses. The TCL tests are the primary suite during development, with 51,445 distinct test cases that expand to millions of runs. TH3 is a proprietary harness of about 1,055 thousand lines of C that delivers 100 percent branch coverage and 100 percent MC/DC coverage of the core, the coverage level behind what sqlite.org calls aviation-grade testing. SQL Logic Test runs 7.2 million queries and checks that SQLite gives the same answers as PostgreSQL, MySQL, SQL Server, and Oracle 10g. And the dbsqlfuzz fuzzer runs about a billion mutations a day, mutating SQL and the database file together. On top of that come out-of-memory, I/O error, crash, and power-loss tests, and a pre-release TH3 soak of about 248.5 million tests.
