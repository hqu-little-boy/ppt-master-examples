So what is inside that library? SQLite compiles SQL into bytecode and then runs that bytecode on a virtual machine, and the code is organised as one stack of eight layers. At the top is the interface. The next three layers, tokenizer, parser, and code generator, form the SQL compiler. The bytecode engine, the VDBE, executes the program, and together with the interface it forms the core. Below it, the backend has three layers: the B-tree, the pager or page cache, and the OS interface, called the VFS. In API terms, sqlite3 prepare v2 is the compile step that produces a bytecode program in a sqlite3 statement object, sqlite3 step runs it on the virtual machine, and the backend stores everything as B-trees made of fixed-size pages.
